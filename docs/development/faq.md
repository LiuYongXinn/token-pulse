# 常见问题

安装与日常操作见[使用指南](user-guide.md)，开发环境问题见[贡献指南](contributing.md)。

## 是否需要 API Key 或单独登录？

本地日志统计不要求 API Key。账户额度是可选连接，通过用户选择的本地 Codex 程序与已有登录的 Home 获取。TokenPulse 不新建自己的登录流程；没有可用登录时，先在相应 Codex 客户端登录，再重新连接。

## 为什么装好以后没有统计？

依次检查“设置 → 数据来源”中的来源是否已保存并启用、所选 Home 是否是实际使用的目录、日志是否可读，以及日期 / 来源 / 会话筛选是否排除了已有记录。首次历史读取需要时间，具体状态看“采集诊断”。

普通浏览器预览不连接桌面采集器，也不会自动生成演示消费。要查看真实本地数据，使用安装版或桌面开发入口。

## Token 总量为什么与分项相加不一致？

缓存命中是输入总数的包含项，推理输出是输出总数的包含项，直接将全部字段相加会重复计数。某些日志只能确认总量而不能确认全部分项，此时保留可信总量，缺失分项显示未知。上下文大小、模型窗口上限和累计消费也有不同含义。

详细规则见[采集与核算设计](../design/collection-accounting.md)。

## 估算金额是不是实际账单？

不是。金额来自本地用量与价格规则，可能包含默认 Standard、上下文档位或缓存写入量的明确参考假设。订阅、工具、多模态和地区等实际计费条件不能由这一金额完整推断。查看明细中的价格依据及覆盖情况，不将参考估算当成真实扣款。

## 为什么有 Token，却显示未计价？

可能是模型没有对应报价、必要输入 / 输出 / 缓存分项不足，或价格规则存在歧义。缺少报价不影响已经确认的 Token 用量。对支持的模型，默认参考估算可处理一部分缺失模式证据，但仍会明确标注假设。

先查看明细和价格依据，再检查自定义规则与模型别名。详见[默认参考费用估算](../requirements/reference-estimates.md)。

## 为什么日期切换后账户额度不变？

日期、来源和会话筛选改变本地消费范围；账户额度仍表示当前连接账户的服务端额度窗口。两者分别查询，不使用本地 Token 或费用估算反推账户剩余比例。

## 为什么额度显示未知，倒计时结束后也没有变成 100%？

未连接、登录不可用、服务读取失败或字段缺失都会保留明确状态。倒计时只是时间展示；到达重置时间后需要等待服务读取的新快照。服务未提供某个窗口时，应用不会猜测它的百分比。

## 关闭窗口后应用是否还在运行？

关闭主窗口、隐藏小窗或停用任务栏入口不等于退出应用。后台采集仍可继续。需要完全结束时，使用系统托盘的明确退出操作。

## 小窗穿透后怎样恢复？

启用穿透前应确认已经注册并验证恢复快捷键。可以使用恢复快捷键或托盘的恢复交互入口；发生快捷键冲突时先解决冲突，不依赖已经被其他应用占用的组合键。

## 任务栏入口没有出现怎么办？

检查任务栏显示是否启用，并查看应用报告的任务栏状态。任务栏空间、Explorer 结构与系统行为都可能影响嵌入。可以启用失败回退到小窗，或继续从主统计窗口查看数据。当前实际系统验证以 Windows 10 为主，不将全部 Windows 11 任务栏结构视为已验收。

## 数据存在哪里？可以安装到 C 盘吗？

独立安装默认以程序目录为根，正式数据位于 `.local/data/release/`；源码开发以仓库为根，开发数据位于 `.local/data/dev/`。`TOKENPULSE_PROJECT_ROOT` 可显式指定本地根目录。

1.0.0 曾限制系统盘；1.0.1 源码与构建已支持包括 C 盘在内的可写本地盘符。应按实际安装版本判断，不套用旧记录的限制。网络共享和设备路径不作为数据根目录。

## 隐私模式是否会加密或删除数据？

不会。隐私模式隐藏展示中的金额、路径和敏感名称，应用数据库和原始来源日志仍存在。公开问题截图前可以启用隐私模式，并检查截图中是否仍有其他个人信息。

## 重建账本与重读来源有什么区别？

重建账本重新核算已保存的用量；“重读已启用来源”重新读取指定来源的日志，验证候选后再替换当前结果。来源日志保持只读，取消或失败保留已有结果。旧版本没有识别的记录需要按问题性质选择操作，不把两种操作混用。

## 为什么源码里有导出或备份界面，应用里却没有？

仓库保留了设计过程和历史原型，其中部分扩展已取消。正式界面没有通用导出、备份恢复或数据清除入口；应以当前应用和交付记录为准。

## 如何报告问题？

在 [GitHub Issues](https://github.com/LiuYongXinn/token-pulse/issues) 提供应用版本、Windows 版本、复现步骤、预期 / 实际结果，以及脱敏截图。采集问题请补充来源状态或受限错误代码；显示问题可补充缩放比例、多屏情况和任务栏设置。

不要公开上传 `.local/` 整个目录、认证文件、签名私钥、原始会话日志或未脱敏数据库。需要示例记录时，先移除凭据、提示内容、路径和个人标识，同时保留与问题相关的字段结构。
