# 使用指南

本文面向安装包用户。项目介绍见[首页](../../README.md)，问题排查见[常见问题](faq.md)，源码开发见[贡献指南](contributing.md)。

## 安装与启动

从 [GitHub Releases](https://github.com/LiuYongXinn/token-pulse/releases/latest) 下载 Windows x64 的 `TokenPulse_<版本>_x64-setup.exe`，运行安装器并选择当前用户可写的本地目录。应用使用 WebView2；缺少运行时时，安装器的引导下载需要网络。

1.0.0 要求安装在非系统盘；1.0.1 的源码和构建已允许系统盘等可写本地盘符。请以实际下载版本为准。网络共享路径不作为应用数据根目录。

启动后可从系统托盘打开统计窗口、显示小窗或明确退出。关闭窗口与退出应用是不同操作；隐藏窗口时后台采集可继续。

## 配置本地来源

1. 打开“设置 → 数据来源”。
2. 使用本地来源检测，检查返回的候选目录；有多个 Codex Home 时确认自己实际使用的目录。
3. 也可使用目录选择器选择自定义 Codex Home。
4. 确认保存并启用来源，然后到“采集诊断”查看扫描、读取和错误状态。

检测和目录选择用于形成可检查的配置，选择后仍需要明确保存。来源日志只读；应用将解析后的账本写入自己的数据库。首次读取历史日志可能耗时，页面显示为空时先检查来源是否启用、目录是否可读，以及日期范围是否包含已有记录。

暂停来源用于停止后续读取，移除来源不等于清除已经保存的历史账本。

## 查看统计

| 页面 | 用途 |
| --- | --- |
| 总览 | 当前范围 Token、已计价部分估算、分项趋势、近期活动、最近会话和可选账户额度 |
| 模型 | 按模型聚合，比较用量和费用 |
| 项目 | 按项目聚合，查看消耗来源 |
| 会话 | 查看会话标题、消费和上下文信息，打开会话详情及可识别回合 |
| 明细 | 逐条查看用量、精确字段、来源关联和价格依据 |
| 采集诊断 | 查看读取状态、缺口与问题，明确重读已启用来源 |
| 设置 | 管理来源、显示、任务栏、价格和应用更新等配置 |

先选择日期范围，再按来源、模型、项目或会话缩小范围。设置的显示时区参与日期解释和时间展示。

统计刷新时可以保留上一次结果，并明确显示旧结果或读取失败。分页快照过期后，使用界面中的“重新查询”获取新的完整结果，不把新旧分页拼接。上下文大小与累计消费分别显示，不能将上下文数字当作重复消费加入总量。

## 悬浮窗与任务栏

从主窗口的显示小窗入口打开悬浮窗。紧凑模式适合常驻查看，展开模式展示更多分项；可置顶、调整透明度，并选择全部来源或固定会话范围。小窗的“打开统计”会带入对应统计范围。

在“设置 → 显示与窗口”调整窗口相关选项。启用鼠标穿透前需要先确认可用的恢复快捷键；恢复入口也可从托盘访问。小窗隐藏后，可以再次从主窗口或托盘显示。

任务栏显示可从主窗口快捷入口或“设置 → 任务栏显示”开启。设置中可选择布局、位置、显示项目及失败时是否回退到小窗。

- 悬停：查看 Token 分解、计价覆盖和账户额度详情。
- 单击：打开现有展开小窗。
- 双击：打开同范围统计。
- 右键：访问显示设置、隐私和隐藏等操作。

任务栏的空间与 Explorer 结构可能影响显示。失败时以应用给出的状态和回退结果为准；主统计窗口仍可用于查看数据。

## 连接账户额度

账户额度连接是可选的，本地日志统计可以单独使用。

1. 在数据来源设置中的账户服务配置区域检测或选择本地 Codex 程序。
2. 检查程序路径，并选择已有登录的 Codex Home。
3. 保存配置后明确连接；如没有可用登录，先在对应 Codex 客户端完成登录，再回到 TokenPulse 重新连接。
4. 查看服务提供的额度窗口、快照时间和重置时间；有多个额度桶时选择对应桶。

TokenPulse 复用本地服务管理的登录状态，不提供独立的登录或设备码流程。缺失周期显示“未提供”，没有连接显示未连接状态。倒计时结束后等待服务返回新额度，不会自行把剩余比例设为 100%。

账户额度属于当前连接账户。本地日期、来源和固定会话筛选不会改变它的统计范围。

## 费用与价格规则

估算金额只对应可以计价的部分，查看金额时同时查看覆盖比例、未计价 Token 和明细中的依据。

内置离线价格目录提供参考价格；有适用的自定义价格或来源规则时按相应规则处理。实际处理模式未知时，支持的模型可按 Standard 参考报价估算；缺少可靠请求输入时的上下文档位、未知缓存写入量等假设会在明细中说明。

在价格规则设置中可维护自定义规则和模型别名，并查看历史价格及后台重估任务。修改价格不修改原始 Token 用量。具体口径见[默认参考费用估算](../requirements/reference-estimates.md)及[价格设计](../design/price-accounting.md)。

## 隐私、数据目录与更新

隐私模式在主窗口、小窗和任务栏共享，隐藏费用、来源路径及敏感名称。它只改变展示，不删除数据，也不提供磁盘加密。

独立安装时，应用默认将自己的可写数据放在程序目录下的 `.local/`，正式数据库位于 `.local/data/release/`。源码开发时以仓库为根，开发数据库位于 `.local/data/dev/`。显式设置 `TOKENPULSE_PROJECT_ROOT` 时以该本地根目录为准。详细路径见[本地数据与缓存](project-local-storage.md)。

通过应用更新入口检查 GitHub Releases 新版本。项目更新签名由应用验证，普通用户无需输入签名密钥。手动下载时也可核对 Release 提供的 `SHA256SUMS.txt`。

更新或移动目录前应明确退出应用，避免文件仍被占用。移动程序与保留统计数据时，需要同时考虑对应的 `.local/` 目录。正式界面没有提供通用数据库导出、备份恢复或数据清除功能，不能把旧设计原型中的入口当成已实现功能。
