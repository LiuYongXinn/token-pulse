## 设计原则

本轮把设计重点放在操作件：主按钮、次按钮、图标按钮、分段选择具有明确的层级和状态，不能只改变页面背景色。三个方向共享黑白银灰范围，通过轮廓、表面明暗、边线与按压反馈区分。

总览围绕可信 Token、趋势和账户额度建立阅读顺序，减少重复卡片。完整中文导航保留。数据字体使用本地 `Bahnschrift`，正文使用 `Segoe UI Variable Text` / `Segoe UI` / `Microsoft YaHei UI`；无需下载字体。数字采用等宽数值排版。

### A · 银雾

浅银侧栏配白色内容表面，左对齐读数与趋势，右侧独立显示账户额度和最近会话。总量与分解整合为开放区域，减少一层卡片。

```text
导航 | 标题、操作与筛选
     | 总量、费用、分解        | 账户额度
     | 用量趋势              | 最近会话
     | 活动热力图            | 采集状态
```

按钮采用胶囊轮廓，图标嵌入小圆形表面。主操作使用炭灰，次操作使用白色与银灰边线。轻微阴影与内侧高光表达表面层次；悬停上移 1 px，按下下沉 2 px，选中分段呈白色浮起状态。

[总览](../images/ui-direction-a.png) · [按钮设计板](../images/ui-buttons-a.png) · [悬浮窗](../images/ui-mini-a.png)

### B · 碳素

横向导航增加趋势可用宽度；关键读数通栏排列，下方为大幅趋势与额度，活动与会话横向并列。

```text
品牌、横向导航、采集状态
标题、操作与筛选
总量 | 费用 | 缓存占比 | 未计价 Token
用量趋势                 | 账户额度
活动热力图               | 最近会话
```

按钮采用切角轮廓和实体底边。主操作使用银色，次操作留在石墨表面。图标与文字之间使用细分隔线。按下下移 2 px 并收起底边，形成机械操作反馈；当前日期通过底部银线和文字同时表达。切角按钮的键盘焦点使用内部描边，避免外部轮廓被裁切。

[总览](../images/ui-direction-b.png) · [按钮设计板](../images/ui-buttons-b.png) · [悬浮窗](../images/ui-mini-b.png)

### C · 纸墨

纯白工作区与黑色操作件形成鲜明对比。项目活动放在趋势左侧，费用置于项目区域下方；数据分解紧邻大读数，额度和最近会话位于右侧。

```text
导航 | 标题、操作与筛选
     | 总量                 | Token 分解
     | 项目动态 | 用量趋势  | 账户额度
     | 费用估算 | 活动      | 最近会话
```

按钮采用黑白印章感：1.5 px 深色轮廓、2–3 px 偏移阴影，主操作为黑底白字，次操作为白底黑字。悬停向左上移 1 px 并扩大阴影；按下向右下移 3 px，阴影归零。分段选择使用黑色实心选中块，导航沿用同一印章造型。

## 按钮与页面交互

每个方向都有独立按钮设计板，展示主操作、次操作、分段选择、图标操作，以及默认、悬停、按下、键盘焦点、不可用五种状态。固定状态样本用于比较；实际按钮也有相应反馈。

原型提供七个导航页面：总览、模型、项目、会话、明细、采集诊断、设置。日期和来源筛选更新本地演示统计；会话支持搜索和详情弹窗；用量柱形支持点击和键盘查看；隐私模式隐藏名称、路径、费用与账户信息；小窗固定展示今日全部来源，不随主窗筛选变化。

采集暂停、重建、重读、账户连接和任务栏预览仅表达交互，不执行真实操作。热力图点击显示对应日期的演示说明。模型与明细使用代表性样本，并非完整生产视图。

## 验证与实施边界

已在 Chromium 检查 1440、960、390 px 宽度，页面没有横向溢出；表格使用独立滚动容器。检查三个方向的导航、日期切换、搜索、详情关闭、隐私开关、小窗展开和分段选择，未出现脚本错误。已查看桌面与窄窗口截图，修正窄屏图标可见性及图表文字缩放。减少动态效果偏好会关闭按钮过渡。

三版提案本身不修改数据、核算和账户契约。选定银雾后，已分模块将变量与操作件迁入共享主题，并完成主窗、小窗、任务栏设置及应用图标改造；正式实施和真实 DTO / Tauri WebView 验证记录见[银雾完整 UI 设计与实施](silver-mist-ui.md)。本文件中的截图和交互仍为选型阶段原型。
