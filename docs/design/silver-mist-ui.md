## 视觉系统

银雾通过明度、边线、轮廓和留白建立层次。页面使用淡灰底，侧栏略深，信息容器为白色；主操作使用炭灰。图表、状态、选择框、进度与焦点统一保持中性色。

|语义|浅色值|用途|
|---|---|---|
|背景|`#F3F3F3`|内容工作区|
|侧栏|`#E8E8E8`|导航与底部状态|
|内容表面|`#FFFFFF`|表格、趋势、额度、设置面板|
|次级表面|`#F8F8F8`|设置分组、表格标题、依据区|
|主文字|`#292929`|标题与关键数值|
|次文字|`#686868`|说明、元信息、单位|
|边线|`#DEDEDE`|分隔与输入轮廓|
|主操作|`#363636`|小窗、保存、发布等主要动作|
|非缓存 / 缓存 / 输出|`#626262` / `#BCBCBC` / `#898989`|分解与完整分项趋势|

正文使用本地 Segoe UI Variable Text / Segoe UI / Microsoft YaHei UI，数值使用 Bahnschrift / Segoe UI 和等宽数字。控件为胶囊轮廓，内容面板使用较小圆角；阴影轻微，侧栏当前页呈白色浮起表面。

共享主题位于 `ui/src/shared/silver-mist.css`，在各功能样式之后加载。统一语义变量同时覆盖浅色与深色，避免每页重复维护颜色。SVG 图标由 `Icon.tsx` 提供，关键操作使用 `ActionButton.tsx` 保留原生按钮语义和事件。

## 按钮与操作层级

|类型|视觉规则|典型操作|
|---|---|---|
|主按钮|炭灰底、白色文字、内嵌圆形图标、轻阴影|显示小窗、保存、发布|
|次按钮|白底、银灰细边、深色文字|刷新、重置草稿、恢复|
|轻按钮|透明或浅灰表面|托盘操作、查看全部、辅助入口|
|图标按钮|紧凑圆形操作区、统一细线 SVG|小窗置顶、展开、隐藏|
|分段选择|银灰轨道、选中项白色浮起|日期快捷项、时间粒度、设置页签|

默认、悬停、按下、键盘焦点、选中、处理中和禁用具有不同反馈。主窗口操作按钮的图标嵌入小圆面，减少文字与图标的松散感。悬停与按下只有小幅位移；小窗图标按钮保持固定位置。减少动态效果偏好会关闭过渡，高对比模式提供明确的系统边线和焦点。

图标为装饰时隐藏于辅助技术；图标独立按钮保留 `aria-label` 和悬停说明。分段使用 `aria-pressed` 或原设置页签语义。日期原下拉选择保留，包括自定义范围，新增快捷项调用相同状态逻辑。

## 小窗与应用标记

紧凑小窗为 280 × 220 DIP，突出 Token 与估算，保留范围、缓存、刷新、统计、隐私和独立额度。展开小窗为 360 × 380 DIP，补充分项、起点与范围操作。完整且与可信总数一致的分项才能显示比例条。

置顶、展开 / 收起和隐藏使用统一细线图标，按压状态保持明确。紧凑小窗留出真实额度更新后的高度预算，底部状态不会被裁切。会话选择与额度详情继续使用受约束的内部弹层。

- [紧凑浅色](../images/silver-mist-mini-compact.png)
- [展开浅色](../images/silver-mist-mini-expanded.png)
- [会话 / 起点选择](../images/silver-mist-mini-scope.png)
- [紧凑深色](../images/silver-mist-mini-dark.png)

应用 / 托盘图标由 `scripts/generate-icons.mjs` 确定性生成，采用银白圆角底和炭灰脉冲线，与界面标记统一。32 px / 128 px PNG 与 256 px ICO 保持中性色；通过 4 倍采样保留小尺寸轮廓，不依赖图片服务。

## 数据、主题与状态规则

统计、价格和账户继续使用既有 IPC 契约。费用估算与账户额度分别说明，未知值、真实零和未计价保留各自状态。总览趋势只有在完整分项之和等于可信总量时绘制堆叠；其他桶保留可信总量柱。缓存 / 推理包含关系继续说明，数据不因为视觉变化被重复相加。

新数据库初始主题为银雾浅色，前端未读取偏好时也使用浅色。既有数据库保存的深色 / 跟随系统选择继续有效；主题写入仍使用精确修订、原子保存、失败保留与隐私屏障。已保存的深色用户可在“设置 → 显示与窗口”切换银雾浅色。

正式浏览器预览不提供本地采集，显示未连接引导。合成 DTO 只存在于测试和截图脚本，不进入生产包。列表截图包含精确大整数和未知值边界样本，用于验证实际排版，不代表真实用户消费。
