# 默认参考费用估算设计

2026-10-07 源码调整；不代表已经替换本机安装或发布新版本。需求见[默认参考费用估算](../requirements/reference-estimates.md)。本设计更新[模型价格与计费条件](price-accounting.md)中未知模式一律未计价的旧行为。

## 选择顺序

保留现有确切模型 / 别名、来源范围、优先级、价格修订及估价时点匹配。自定义或独立固定规则先于目录参考估算。已确认实际模式的请求继续进入严格条件选择；关联无效或该模式缺报价时不退回猜测模式。

无适用固定规则、实际模式未知且当前历史目录收录条件模型时，使用 `select_standard_estimate` 选择同一不可变目录的 Standard 报价。可靠单次请求输入必须通过现有 `project_input` 校验并关联完整消费，才能选长 / 短上下文档。输入超过目录阈值选长档；缺少完整关联时暂选短档并记录 `context_assumed=true`。不分档报价的该标志为 false。

## 数量与假设

已有普通输入、缓存命中、缓存写入和输出四费率公式保持。已知正数写入必须扣除普通输入后按写入费率收费。目录提供写入费率而数量未知时，仅对传入计算函数的临时 `UsageVector` 使用零，并记录 `cache_write_assumed_zero=true`。原始和核算 DTO、消费事实、观察 JSON、Token 聚合及检查点保留 null。未知缓存命中或其他必要分项继续走原有不足校验。

`SelectedPrice::AssumedRequest` 保留目录条件报价的真实规则身份；存储层仍核对不可变父规则、目录、模型、模式和上下文索引，不能以参考估算绕过身份校验。

## 公开依据与缓存

公开 `PriceMatchBasis::OfflineAssumedReference` 包含目录、上下文档、上下文是否假设、写入是否暂按零和全球 API 参考范围；没有 `actual_tier`，不能冒充响应确认。明细显示 Standard 参考估算及具体假设；模型 / 项目页、费用提示与价格目录说明默认参考口径。

费用缓存版本从 6 升至 7，指纹和集合身份随之变化，旧缓存不参与新计算。查询即时补算与后台重建复用同一求值入口；无需改变消费版本、数据库 schema 或重新采集历史日志。历史目录选取和显式自定义规则的生效时间不变；核实日之前无目录的事件仍需指定估价时点或历史自定义价。

独立金额预期覆盖未知模式、已知 / 未知写入、缺关联的参考短档、可靠输入边界、确认模式缺报价、自定义覆盖、模型别名和历史修订。SQLite 回归覆盖生产查询、后台缓存、跨页原快照、重新打开及账本 / 检查点不变；旧缓存版本 4 / 5 / 6 被排除。契约与浏览器检查覆盖假设字段、实际模式未确认、隐私与窄屏明细。
