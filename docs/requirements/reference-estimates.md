# 默认参考费用估算

## 目标

本地日志能够确认 Token 消费，但没有实际处理模式时，仍应提供可用的参考费用。不能因为来源长期不提供该字段，让已收录模型的历史和后续用量一直未计价。

## 行为

- 自定义价格规则及来源专用价格保持原优先级。
- 有响应确认的实际模式时，继续按已关联请求选择对应报价；不能用 Standard 掩盖已确认模式的缺报价问题。
- 实际模式未知、没有适用固定规则时，使用同一历史目录中的 Standard 参考报价。
- 有可靠完整请求输入时选择对应上下文档位；否则暂用短上下文参考档并明确标注假设，不能用累计用量推断单次请求长度。
- 缓存写入量未知时，仅在参考估算的计算副本中暂按零处理，并标注该假设；原始用量、统计分项和采集检查点保持不变。
- 模型未知、目录缺报价、必要输入 / 输出 / 缓存命中分项不足或规则歧义等情况仍应说明未计价原因。
- 明细区分参考假设和响应确认，参考金额不作为订阅账单、地区加价或工具费用。

## 验收

- 模式未知的已收录模型能够返回参考费用，不要求用户逐模型录入单价。
- 272000 / 272001 输入边界、缓存命中、已知缓存写入和全部输出按选定档位计算。
- 即时查询、持久缓存、后台估价、历史分页和重新打开数据库的结果一致。
- 升级后不继续使用旧版未计价缓存；Token 账本与未知分项不被补造。
- 明细可查看模式、上下文和缓存写入的具体假设；隐私模式继续隐藏金额及价格依据。
